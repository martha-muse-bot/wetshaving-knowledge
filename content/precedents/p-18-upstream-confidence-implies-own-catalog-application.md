*Status: standing · Source: [[Precedents]]*

**Statement:** A catalog correction proposed to nmrs at 100% confidence
(the PR bar) is applied to our own catalog in the same turn. If we are
confident enough to assert a mapping upstream, withholding it from
ourselves is incoherent.
**Scope:** Catalog corrections only (correct_matches / catalog YAML).
Code fixes to nmrs (e.g. PR #4's override-manager fix) have no
own-catalog counterpart — our matcher is separate code — and are excluded.
**Escape hatch:** If our own dataset evidence contradicts the upstream
mapping (our posts show the string means something else here), hold for
joint review instead of applying blindly. The contradiction, not the
quota, decides.
**Established by:** Yusuf ruling (2026-10-28, user) — PR #3's DG
Yusuf→Yuzu mapping applied to our catalog the same day; the WK/CL Yusuf
string followed from the user's 2026-10-27 typo ruling + the string's own
maker tag, not from PR #3 (PR #3 covered the DG string only).
