*Status: standing · Source: [[precedents|Precedents]]*

**Statement:** A shaving brush handle sold on its own — no knot set — is a catalog entry in the `handle` category (the knot parallel: sold standalone, so it is a product). Complete brushes stay `brush` entries. A handle maker's standing model, shape, or type is one entry (P-17 model-attribute: a handle model is one entry; finishes, materials, colors, and sizes are attributes/variant aliases, not entries). A drop colorway becomes a handle entry only on maker primary evidence naming it as a standing product (a live maker/store listing); multi-author dataset spread alone does not make a drop an entry — and an attested handle entry would be matcher-dead in any case (see Matcher implication). A drop name used by only 1–2 authors is one owner's brush, not an entry (P-19 custom commissions; P-11 unresolved). The matcher splits knot+handle composite strings via handle_id/knot_id. Razor handles are NOT handle entries — they stay in `razor` (e.g. Maggard MR-series "Handle Only" razor handles are razor entries).
**Established by:** User decision 2026-11-18 ("Add the handle category + harvest the artisan handles"). Evidence base: [[hardware/dogwood-handcrafts|Dogwood Handcrafts]] maker page (3 handle types: Hybrid $150, Acrylic $75, [[hardware/cast-object|Cast Object]] $150; dogwoodhandcrafts.com/brushes); Maggard Razors handle-only listings (Sky Blue $15.95, Sandy Pearl $22.95); Timeless TRBR adjustable brush handle ($69, Maggard); Chisel & Hound products.json (handles sold unknotted in one-off numbered drops — no standing models, no entries); Dogwood named-drops dataset study ([[hardware|Hardware lore]], established 2026-10-23).
**Boundary:** This supersedes the Oct 2026 "multi-owner Dogwood drops are candidate handle entries" framing in [[hardware|Hardware lore]] for the entry decision: the drop census itself stands (Aurora 24 authors, Starscape 11, Seascape 17, Andromeda 14, Valley of Ashes 8, Lava Flow 8, Arcane Abyss 7, Nightscape 6, Milkglass 4), but none of the nine clears the bar — no maker listing names any drop as a standing product (the one listing URL found in dataset notes, Milkglass etsy.com/listing/802572592, is dead, HTTP 410, 2026-11-18), and attested status cannot carry a handle entry (see Matcher implication). The photo-evidence route could promote a drop later (an SOTD photo showing the drop handle is primary evidence) — a validator/photo-sweep follow-up, not part of this harvest. One-off drop handles (Chisel & Hound numbered drops, Muninn, Summer Break Soaps customs, single-author Dogwood drops like Good Gully 2 authors / Mighty Stag 1 author) resolve at brand level per P-19. Mozingo yields nothing: the Jefferson handle style is 2 authors and the maker site has a single 2019 Wayback capture with no retrievable handle catalog; its ZT/B codes are knots, out of scope here.
**Matcher implication:** NONE needed for the harvest — but the tier limit is load-bearing: `BRUSH_INDEX` (tier-1) covers brush/handle/knot, while `BRUSH_MID_INDEX` and `BRUSH_UV_INDEX` cover category `brush` ONLY, and the tier-2/3 fallbacks in `match_brush` return complete brushes only. So a handle entry matches ONLY at tier-1 (verified). An attested/corroborated handle entry would never match any string. Any future proposal to make tier-2 handle/knot entries match needs a matcher change (widen the mid/UV brush indexes and the fallback kinds) with its own A/B — it is not part of P-26.
**Applied:** 2026-11-18 — handle category created; verified entries: `handle/dogwood-handcrafts-hybrid`, `handle/dogwood-handcrafts-acrylic`, `handle/dogwood-handcrafts-cast-object`, `handle/maggard-razors-sky-blue-base`, `handle/maggard-razors-sandy-pearl-base`, `handle/timeless-trbr-adjustable-aluminum-shaving-brush-handle`.
