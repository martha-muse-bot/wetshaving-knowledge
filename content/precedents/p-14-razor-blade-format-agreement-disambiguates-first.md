*Status: standing · Source: [[Precedents]]*

**Statement:** Blade and format must agree within a post. When a blade string is
ambiguous across formats or products, the format of the razor named in the same
post decides (DE razor → the DE blade; AC razor → the AC blade) — and vice versa
when a razor name is the ambiguous one. This check runs BEFORE the popularity
default (P-07), which applies only when the pairing gives no signal.
**Established by:** user ruling on §B1 bare "Kai" (2026-10-21) — no blanket
alias to the DE entry; per-post razor format decides.
**HARD CONSTRAINT (user, 2026-10-21):** no default — popularity, loose, or
otherwise — may ever resolve a blade AGAINST the paired razor's format. Bare
"Feather" in an AC-razor post defaulting to the DE Hi-Stainless is the named
violation ("in no case"). When the razor's format is known and no
within-format pick is defensible, the string stays ambiguous WITHIN that
format (or loose-aliases within it, per P-15) — it never crosses formats.
**Relied on by:** §B1 bare "Kai"; §B3 bare "Personna" (razor cross-check, as the
team had proposed); generalizes the earlier per-post Schick decision (B2).
