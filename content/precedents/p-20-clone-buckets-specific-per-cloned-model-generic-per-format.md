*Status: standing · Source: [[Precedents]]*

**Statement:** Clones of a named model with a coherent multi-author family get a
specific bucket entry (brand Other, never under the cloned maker); other known
clone strings go to generic per-format fallback buckets (Other DE/AC/Injector
Clone). Buckets carry a blade-format type so P-14 agreement still works. A
single-author clone term goes generic, not specific. Maker-named clone products
are entries, not buckets. Multi-razor/essay strings stay clustered (P-11).
**Established by:** Clone-bucket design ruling (2026-10-28, user tap: specific +
generic fallback) — first application: Kai Captain + Kai Kamisori Clone (88/4),
Futur Clone (226/43), generic DE (92/37), AC (177/9), Injector (27/2, tier
unverified on the 2-author basis).
**Contrast:** P-19 (single-owner commissions are not entries) — clones are
multi-owner by nature, so they get buckets, not brand-level resolution.
