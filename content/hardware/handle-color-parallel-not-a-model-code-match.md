**Handle-color parallel, NOT a model-code match:** vshod's Blue
Cobalt BADGER brush shares the cobalt-blue handle color with the
established 505BC (Cobalt Blue, 28mm bleached BOAR) — same handle
shell, different knot family (M-series Manchurian). Do not cite the
vshod badger listing as a 505BC; its model code is unpinned.
