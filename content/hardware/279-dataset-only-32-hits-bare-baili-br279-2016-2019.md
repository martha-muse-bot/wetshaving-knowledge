*Confidence: established · Source: [[Hardware lore]]*

**279 = dataset-only (32 hits, bare "Baili BR279", 2016–2019).** Type
unidentified — never appears in forum/shop sources found this run.
Lead: is this a China-domestic model or a discontinued Western SKU?
**RESOLVED 2026-10-27 — 279 = a Baili butterfly/TTO, distinct from the
179 butterfly (number-key rule: different number = different product,
do NOT fold into 179).** Dataset scope CORRECTED: all 32 hits are ONE
author (whiskyey), Jul–Aug 2017 only — a single Austere August run,
not a 2016–2019 presence. Type evidence is the poster's own words:
2017-07-21 "I hear the 3 piece designs are even better" + 2017-08-14
"I've got a 3 piece Baili on the way" (which materializes as BR171 in
his Sept 2017 posts) — so the 279 is NOT a 3-piece; and the TSR
DB279 is explicitly a butterfly ("a little loose when open, but
closes down tightly and shaves pretty much like a Tech", TSR
Solimo-blades thread #15). Character: light/cheap-feeling ("doesn't
have the weight or build quality of a SS razor", "kinda cheap and
light/plastic feeling"), first impression "fabulous... effortlessly
close", by mid-August "the biggest let down". Channels: Groomatorium
US, $7.99 (dataset price-tagged string); Amazon UK Solimo kit as
DB279 (bundled with Personna Tomy blades) — DB279 is the transposed-
prefix form of the same number (cf. DB179 precedent). The TSR
poster's "Baili rebrand / Superspeed clone with tabs covered" framing
is a QUESTION the thread owner never confirms — record the
Superspeed-pattern description as lead, not as the 279's identity.
**LEAD left: 279 = the LONGER-handle Baili TTO?** B&B 600602 documents
TWO Baili TTOs — an 85 mm-handle version and a longer one sold under
Amazon's Solimo brand — but names neither number; the Solimo-kit =
longer-TTO link is documented, the DB279 = Solimo-kit link is
single-poster, so 279-as-long-TTO is a hypothesis, not established.
Settles on a 279 listing naming handle length or a side-by-side
179/279 photo. Catalog: the existing unverified `baili-br279` /
`7-99-baili-br279` clusters are the butterfly/TTO entry; fold
"DB279" strings into it, never into 179.
