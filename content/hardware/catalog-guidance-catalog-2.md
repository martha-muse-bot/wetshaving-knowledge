**[[lineages/catalog-guidance-catalog|[[lineages/catalog-guidance|Catalog guidance]] [catalog]]]:** keep A/B/C as distinct knot variants (the existing glossary "variant attribute, never separate entries" line means: never create separate *brush-product* entries on the letter alone — the letter is a knot attribute of the brush — but never fold A into B or C in matching either; a "G5B" string is not a G5A string with a typo). **GUARD — "G5" alone is ambiguous across makers:** AP's G5A (German fibers, assembled in China, per two independent B&B firsthand voices, 612243 p.2) is NOT Maggard's G5 (Chinese fibers, assembled in China, same thread) and NOT Frank Shaving's "FS G5" (B&B 647823 warning: "the AP G5A is not to be confused with the FS G5"). Bare "G5" strings need a maker/retailer signal before folding to AP.
