**Karve post-CB lineup: Overlander / Bison / KMOD (2026-11-03 run).**
- **Overlander — own single-plate head; NEVER takes CB plates.**
Launched Nov 2021 (brass + aluminum at launch; B&B 617266, IG
2021-11-26; stainless and copper came later). The maker's CURRENT
copy (karveshaving.com homepage, live 2026-11-03) names "CB and
Overlander heads" and "CB and Overlander plates" as two SEPARATE
families — "CB and Overlander plates are not compatible with the
Bison" groups them against the Bison head but does NOT merge them
with each other; community confirms the Overlander takes ONE plate
only (B&B 643169: "The Overlander is only available in one BASE
PLATE, Christoper offer many"). Handles ARE thread-compatible across
the line ("The Bison handle fits all of our existing stands and the
CB and Overlander heads"; #10-32 thread per the maker spec block) —
a CB handle on an Overlander head is a parts combo, not a product.
Efficiency lore: mild feel with efficiency ≈ a CB D-plate (multi-owner
consensus); one owner's paper-edge test = fractionally positive
exposure; an owner relay of maker specs says ~0.02 mm exposure with a
narrow gap (lead-grade — not maker-text-verified). ATG-specialist
reputation; blade tabs covered (no widebody variant needed).
**[catalog]:** `razor/karve-overlander` EXISTS (verified) — own entry
stands; CB plate strings (AA–G) NEVER fold to the Overlander and vice
versa (own head/plate family, P-17); a bare "Karve Overlander" is
certain with no plate attribute owed (single plate by design).
- **Bison — aluminum single-plate razor, launched ~Dec 2023 (CORRECTION
to the "2024" framing: in owners' hands by Dec 11, 2023 — B&B Bison
thread first-shave review "Last edited: Dec 11, 2023"; first SOTD use
Dec 28, 2023, frankieIVfingers ×3 "Karve Shaving Co. - Bison
(Aluminum)").** Maker specs (live 2026-11-03): 0.71 mm gap /
0.06 mm exposure, 33.5 g, all-aluminum (bead-blasted, anodized), lowest-profile cap to date, blade tabs
fully enclosed, serialized cap, ~30° vintage-style shave angle; sold
ONLY as a complete razor ("At this time, this razor is only available
as a complete razor"). Prices: $135 CAD aluminum, $169 CAD Glacier,
$149 CAD Mutant Green LE (a dye-shift one-off batch — four named
colorways: Lorne, Rene, Doug, Martin). **[catalog]:**
`razor/karve-bison` EXISTS (verified); [[glossary/mutant-green|"Mutant Green"]]/"Glacier" =
finish attributes, never entries.
- **KMOD Alpha — the experimental line's first product.** KMOD =
**Karve Ministry of Debauchery** — the maker's own words: "where the
experimental work lives: designs that don't fit the standard lineup,
ideas I want to test before deciding if they belong there
permanently. Full razors, individual components, accessories, stands,
brushes, whatever the idea calls for. Some of it will stay limited.
Some will move to the core lineup." The KMOD Alpha: $169 CAD,
three-piece barber-pole handle (two colorways: red cap/blue pommel OR
blue cap/red pommel), built on the STANDARD BISON HEAD ("the same
blade geometry, same enclosed blade tabs, same serialized cap"),
all-aluminum anodized, complete-razor only. **[catalog]:**
`unverified/razor/karve-ministry-of-debauchery-alpha` (corroborated)
— the maker homepage is a PRIMARY evidence route for promotion to
verified; head = Bison (0.71/0.06) as attribute, handle = the product
identity (P-17; a future KMOD product on another head is a different
entry).
- **Lineup status 2026-11-03 (ESTABLISHED):** the maker homepage
currently sells ONLY complete Bison + KMOD Alpha razors; B&B (Karve
Delivery Issues thread, crawled ~Oct/Nov 2026): "The only razor that
is offered is the Bison." The CB FULL RAZOR is off-sale — the CB
lives on as heads/plates. Catalog evidence route for the CB is now
the maker heads/plates pages + photos/Wayback, not the (former)
full-razor listing. Resolves backlog (a).
