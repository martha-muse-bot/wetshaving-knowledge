*Confidence: established · Source: [[Hardware lore]]*

**OEM UNPINNED (lead):** no source names the maker. The ~$12 price and 2016 launch put it in the Chinese zamak-slant pool (same era/price class as the Maggard slant head, $19.95, itself a vintage Mulcuto/Paul Müller derivative per Maggard's own copy) — but Matuhg's comfort comparison argues against it being the identical head, and no head-photo comparison exists. Do NOT cite a Maggard or Mulcuto attribution. Sharpologist's "The Big Slant Showdown" (6 slants: RazoRock Stealth, GBS, Wunderbar, Maggard, Merkur 39C + 1) does NOT include the Stirling — no OEM pin there. Remaining routes: a later Archive retry when stable (Stirling /hardware/ Apr 2017 and /razors/ Jan 2017 captures could not load during an Archive outage) or a Stirling-vs-Maggard head-photo comparison. **Wayback read 2026-11-05 (browser):** CDX queries for "slant" in stirlingsoap.com URLs returned NOTHING (2016–17 and all years); /razors/ has only three captures, all early 2016 (Jan 1, Jan 3, Mar 18) — the Mar 18, 2016 page lists four DE razors (DE3P1S $16.95, DE3P2S $21.95, DE3P6S $16.95, DE3P7S $21.95), no slant (pre-launch). The slant's maker page, if it existed, was never archived. **Reddit corroboration (r/wicked_edge, Sep 2016, "Stirling Soap slant razor - first shave review"):** the slant sold as factory seconds (~$13, "closed out 'Seconds'"); chrome version, long handle + short handle mentioned; heavy; blade alignment fiddly when screwing back on. On maker/OEM the only identification found is a Reddit user comment calling it "a clone of the Merkur 37C" (aaronmil) — a USER claim, not a maker statement; record as a lead only, never as established. **[[CORRECTION 2026-11-05]]:** this entry's earlier claim that the current store "lists no razor at all" was WRONG — the live store still sells DE razors (DE3P1S $25.95, in stock, head options Aggressive/Open-Comb/Standard; head chrome-plated zinc-alloy pot metal, handle CNC machined in Paris, Arkansas, USA; 85 g, 87 mm). Only the SLANT is gone (live site search for "slant" = 0 results).
