*Confidence: established · Source: [[Hardware lore]]*

**[catalog] The Kalyon handle.** The handle shipped with the
TR-2/TR-3 set is named "Kalyon" (B&B 629705 #11: "that TR-3
'Kalyon' handle"; rate-the-shave p.2360: "baptized as The
Kalyon... evokes a minaret from the Ottoman Empire"). Specs
(same single firsthand source): 85mm long, 13.3mm diameter,
75g. "Kalyon" is Turkish for a galleon/warship — the name fits
the Barbaros (Barbarossa) naval theme. Handle strings pairing
OTHER heads with a Barbaros handle ("Mühle R41 on Barbaros
Levened handle" — see below) are aftermarket reuse, not
Barbaros products. Confidence: established (name + set pairing);
dimensions = lead (single source).
