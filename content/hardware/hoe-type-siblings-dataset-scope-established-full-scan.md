**Hoe-type siblings — dataset scope (established, full
scan):** Du Barry, Dorset, and T-Type are all genuine
early-1920s Durham hoe-type models taking the STANDARD
Durham-Duplex blade (streettotheleft summary; B&B wiki
for Du Barry 1922, Gillette-threaded handle, Durham
blades, NOT Gillette-compatible). But their SOTD
footprint is nil: Du Barry = ZERO strings in any year;
T-Type = ZERO genuine strings (all hits are "-type"
false positives: "plissoft-type", "detergent-type");
Dorset = exactly ONE genuine string — luvmy07subie
2021 "~1947 DURHAM DORSET", and it is a HACK post (Feather
Pro AC blade + a Home Depot Personna carpet blade, per
his notes), not a clean product string. The 2022/2023
"Dorset" hits are a Shpongle song link ("Dorset
Perception"), not razors. [[Catalog guidance [catalog]]]:
do NOT create Du Barry / T-Type / Dorset entries on
dataset evidence (zero / zero / one-hack strings); the
models are real and documented for future strings, and
any future Dorset string folds to the Durham-blade
family, never to the hack's AC/carpet-blade setup. The
"~1947" in the Dorset post is poster dating (Durham-
Enders era, plausible, unverified) — never cite it as a
model date.
