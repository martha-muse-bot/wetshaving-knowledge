**(c4-narrow-244) RESOLVED [catalog]:** the WK pattern DOES generalize, but only for makers with genuine parallel soap+cream formats. Method: DB scan grouped soap-category entries by (brand_group, scent key) after stripping format words; census v2 counted ONLY poster strings that literally say 'cream'/'crema' (exact normalized match on the soap field). Headline: 140 verified/corroborated soap-form entries carry cream aliases; ZERO has a cream-form sibling; 3,223 literal-'cream' poster strings route to the 140; ~549 are genuine mis-attribution (Class B). The rest are Class A (the entry IS the cream — correct) or Class C (TTS-classification artifact / poster shorthand for a soap-only maker — routing correct).
