*Confidence: established · Source: [[Product lines]]*

**[catalog] Black Ship Grooming — "Kaito" is a BASE, not a scent
(established 2026-10-24; corrects the 2026-10-21 lineages entry).**
Posters write it base-first: "Black Ship Grooming Kaito -
Fitzgerald" / "Kaito - Whydah" (sgrdddy, July 2026). Earlier
evidence: 2021-06-15 (namziah) "the vegan base (Kaito, I think it's
called) of Captain Scurvy"; 2022-01-23 (wyze0ne) "this 'Kaito' base
is legit af" (Hoptoberfest); the maker's Scrooge description calls
it the "New Kaito shaving cream base." Validators: NEVER create a
"Kaito" scent entry, and never parse "Kaito - <scent>" as a scent
name — Kaito is the base attribute on the scent's entry, exactly
like the GD scent+base key. The Final Voyage pair in Kaito base =
Fitzgerald + Whydah (see [[Lineages]] correction).

**[[ADDENDUM 2026-10-26]] — the full base lineup, answering the
backlog's open questions (dataset mining, sotd_2016–2026_full.json
+ maker blog + Bladetester).** Kaito's launch bracket is now
**by February 2021**: the earliest dataset Kaito tag is
2021-02-22 (WolfSK-88, soap field "Black Ship Grooming - Stolen
Heart kaito base", bought "as soon as I could" = new release),
and the name was still settling in mid-2021 (namziah 2021-06-15:
"the vegan base (Kaito, I think it's called)"). Kaito-base
scents attested in the dataset: **Stolen Heart (2021), Captain
Scurvy vegan version (2021), Hoptoberfest (2022), Scrooge
(2022, maker description), Fitzgerald + Whydah (2026, Final
Voyage)** — plus Crane titled "Shaving Cream" (fall 2025).
**Kaito is NOT Black Ship's first vegan base.** The ORIGINAL
house base was already vegan: 2018-03-15 (reguyw_nothingtolose)
"Two Bits is vegan"; 2019-04-04 / 2019-05-04 (Not_a_robot_101)
Philip's Fougere "vegan, built around a coconut and shea butter
base"; 2019-10-06 (Aresmsu) White Whale "as far as vegan soaps
go"; 2023-07-12 (AdWorried2804, Davy Jones) "BSG's original soap
base ... consists of Coconut oil, Shea Butter, Stearic Acid,
Water, Potassium Hydroxide, Glycerin"; Bladetester corroborates
the coconut/shea/glycerin profile for Siren's Song. So Kaito is
the maker's NEW/SECOND vegan base (a reformulation or renamed
line, ~2020–2021), and some scents exist in both eras
(Captain Scurvy, Captain's Reserve, Cap'n Darkside all carry
trythatsoap soap_vegan SKUs). **"Triple butter" is maker
marketing, NOT a separate base or line**: the maker's blog
("The Art of Smooth Shaves") calls the soap collection "Triple
butter shaving soaps" and says "the triple butter blend and
tallow provide hydration" — but NO poster-quoted ingredient
list for any Black Ship soap contains tallow, and the
"original base" list above is tallow-free. Treat the blog's
tallow phrase as uncorroborated marketing copy: do NOT create
a Black Ship tallow-base entry on it. **"Shaving cream base"
is texture language, not a format split**: the maker calls
Kaito a "shaving cream base" and titles Crane "Shaving Cream",
yet Fitzgerald (titled "Shaving Soap") is Kaito-base per
posters — validators must not split soap vs cream entries on
the title word. **Outlier (single-reviewer lead, not a house
base):** Bladetester lists Christmas Cannons at "argan oil,
lanolin, sunflower oil" — lanolin would make it non-vegan, so
if true it is a seasonal-variant formula, not the house base;
needs a label photo before any catalog use. Confidence:
established (Kaito = new vegan base, launch by Feb 2021;
original base = vegan coconut/shea; triple-butter = marketing;
no evidenced tallow base); the exact Kaito launch announcement
and the Christmas Cannons lanolin note remain leads.
