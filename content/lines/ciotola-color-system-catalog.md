*Confidence: lead · Source: [[lines|Product lines]]*

**Ciotola color system [catalog]:** HairMaker.gr Mandorla page (retailer
copy of maker text): Rossa = bitter almond (Purissima; the 1000ml barber
size is 'a bitter almond stronger cream'); Blu = Sandalo (Oriental);
Gialla = citrus (sweet orange + lime); Verde = menthol crystals,
Eucalyptus globulus, balsamic notes. Bowl color is a SCENT code, never a
product name alone — bare 'Ciotola Rossa' already folds to Purissima; a
future bare 'Ciotola Blu/Gialla/Verde' folds to the mapped scent. Dataset
confirms Gialla = Sweet Orange ('[[lineages/tcheon-fung-sing|Tcheon Fung Sing]] - Sweet Orange (yellow
tub)' ×1) — validator call: merge the two unverified Sweet Orange
clusters (plain + yellow-tub twin). Ciotola Verde identity unpinned —
new lead (313); never conflate with Tabacco Verde (Linea Intenso scent).
