*Status: open · Source: [[Open questions]]*

Soap bases as identity: [[Declaration Grooming]] Milksteak, B&M
Excelsior/Glissant, Grooming Dept Kairos/Mallard — which bases do
posters treat as different products? **GD leg ANSWERED 2026-10-22**:
YES — posters routinely include the base ("Grooming Dept - Amare -
Kairos base", "- Charbon - Janus Tallow"); catalog key for GD =
scent + base, version = era attribute (see [[Product lines]]). **AION
leg ANSWERED 2026-10-23**: the same key holds in the Aion Skincare
era — "Aion Skincare - Mallard Kulfi", "Aion - Chypre Muguet" etc.
carry base×scent identity; the balm/toner/gel are the skincare line.
DG Milksteak and B&M Excelsior/Glissant still open.
**ALL FOUR LEGS ANSWERED 2026-10-24**: the answer is YES for DG and B&M
too — catalog key = **scent + base**, base = era attribute.
- **DG: Bison → Icarus (~2018) → Milksteak (Sept 2019).** Posters tag
"(Milksteak)" / "(Icarus)" / "(Bison)" routinely (226/272/190 soap
hits); Darkfall exists in all three bases, Chaipre in Milksteak +
Icarus — same scent, different base = different product identity.
Maker's FB announcement (relayed B&B 574293 #40, 2019-09-26):
"the Icarus and the older bison base are now officially dead and
are being replaced with this new Milksteak base." Milksteak = bison
tallow + dairy (EWG packaging list). Cautions: "(Bison)" is an ERA
tag — all three bases contain bison tallow, so post-2019 "(Bison)"
strings are legacy pucks; the Icarus scent lineup was distinct from
the bison lineup (B&B 575718 #20), don't assume cross-base scent
equivalents. Full entry in [[Product lines]] [catalog].
- **B&M: White/Black Label → Glissant (2015) → Excelsior (Nov 2018)
→ Omnibus (Sept 2021),** with parallel Latha (lanolin-free,
~2015–2018, 790 hits), Tre Citta (vegan, 2016–2018), Soft Heart
(2019–2021, sold as the "Soft Hearts" line, 454 hits). Seville
spans Reserve/Glissant/Excelsior/Omnibus; one poster owned "42 in
every base" — scent + base is the identity. Cautions: the Excelsior
squiggle symbol also appears on Soft Heart (not Excelsior-alone
evidence); tub-ID: Glissant = clear-bottom tubs, Excelsior =
white-bottom tubs, Omnibus = OMNIBUS on side label. Full entry in
[[Product lines]] [catalog].

**RESOLVED 2026-10-28 ([[Product lines]] B&M Latha addendum)
[catalog]:** Latha = lanolin-free TALLOW base (not vegan — Tre
Citta is the vegan line; the B&B "non-tallow" claim is wrong),
launched ~Jul 2015 (Limon/Oceana), discontinued announced Feb 15,
2018 ("two and a half year run"); post-2018 uses are destash/
retailer remainder. Canonical 10-scent lineup (Daily Lather
history table): Latha (barbershop), Lavanda, Le Petit Chypré,
Limon, Oceana, Sandalwood, Taiga, Figgy Puddin', Unscented,
Velvet (for women). Core-line overlap: Taiga → Soft Heart Dec
2019 → core Winter Dec 2021; Oceana → Soft Heart ~2021 → core
Summer Jul 2023; Le Petit Chypre → Soft Heart Dec 2019. No core
return for Limon, Lavanda, Figgy Puddin', Velvet, or barbershop
Latha. CAUTION: 2021 Soft Heart Sandalwood is a DIFFERENT scent
(Fougère Gothique EdP accord origin) sharing the name — never
fold Latha Sandalwood into it. "Latha Osmanthus" is NOT a
product (frankieIVfingers' DIY: Latha Unscented + Osmanthus
Absolute). "Latha Lavender" = Lavanda mislabel; "Latha
Original" = the barbershop Latha scent (not Unscented). RESIDUAL

(b) Sandalwood name-reuse scent comparison (notes differ:

Oceana release date.

**RESOLVED 2026-10-29 ([[Product lines]] DG addendum) [catalog]:**
NO — one continuous bison formula, July 2016 – Sept 2019. RENAME DATE
CORRECTED: ~mid-Nov 2017 (first community "Declaration Grooming
(formerly L&L Grooming)" strings 2017-11-20), not 2018. Evidence:
(a) maker's own Sept 2019 Milksteak announcement deprecated "Bison
and Icarus" as one continuous base (Sharpologist 2020-03-27, quoting
the maker's statement); (b) the bison ingredient list is identical
pre-rename (B&B 530210, purchase Aug 11, 2017; B&B 522030, early
2017 — same Stearic Acid/Water/KOH/Avocado Oil/Glycerin/Bison
Tallow/Mango Seed Butter/Castor Oil/Fragrance/NaOH/Lanolin/Bentonite/
botanical extracts/Phenoxyethanol/Caprylyl Glycol/Sorbic Acid list);
(c) zero posts anywhere claim a rename-era formula change (the
community loudly flagged Icarus Mar 2018 and Milksteak Sept 2019 —
a rename change would not pass silently); negative dataset-note scan
2017–2018 + web search 2026-10-29. Catalog: all bison-era L&L/DG
soap strings (Jul 2016 – Sep 2019) = the same base formula; "(Bison)"
tags on either name form are the same era tag. Bonus: L&L launched
with a VEGAN formula before the bison base (NoLogonServAvailable
2016 dataset note) — pre-July-2016 L&L strings are a different base,
not bison. NEW LEADS: (a) the maker's June 2018 "State of the

bison packaging ingredient list was never directly captured —

(d) "DFS 2017" — the Nov 2017 event/meetup where the new name
debuted in dataset strings (pin what it was); (4) B&M "Soft Heart"
release list — pin which scents shipped in Soft Heart vs Excelsior
