**Figaro** — THREE-WAY AMBIGUITY, never auto-apply [catalog]. (1) **Italian Figaro** = MilMil76 brand (ex-Elberel Italiana; P.160 kilo brick until 2009; modern Monsieur line TFS-made, milmil76-distributed; red-bowl almond soap = TFS Red Bowl). (2) **Hungarian Figaro** = Caola Cosmetics Ltd, Budapest (founded 1831) — shaving cream (herbaceous, oakmoss) + blades; duki92's 2022-02-04 "(Hungarian)" string is the only dataset attestation. (3) **Barbiere di Figaro (BdF)** = a Netherlands RETAILER's TFS-made house line (Mistero/Classico/Esclusivo/Raffinato/Distinto — five scents, NOT Italian Fern, which is a TFS scent; corrected 2026-11-25, (409)), not a maker. Plus the false friend **B&M Figarose** ([[lines/barrister-and-mann|Barrister and Mann]] scent, unrelated). Resolve per context: "(Hungarian)"/Caola marker → Hungarian; "Monsieur"/"TFS"/"MilMil76"/"Bluice"/"Red" → Italian; "BdF"/Mistero etc. → retailer line; "Figarose" → B&M. Bare "Figaro" with no marker is Italian by default only in a TFS/Monsieur context — otherwise ambiguous. Established 2026-11-25 ([[lineages|Lineages]] run section; B&B 392937 #12, 273653, 483637, 666675 #40).
