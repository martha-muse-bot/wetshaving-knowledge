**TTS** = **T**ry**T**hat**S**oap (trythatsoap.com) — the soap
scent-rating/recommendation site AND the SOTD submission tool ("TTS
suggested this setup", "TTS SOTD submission tool"). **"TTS 2.0"** =
the second TryThatSoap × [[Declaration Grooming]] data-driven scent
collaboration (parfumo lists "Try This Soap 2.0" as a DG fragrance;
Hyvasuomi79 2019-05-03: "the rumored TTS 2.0... make data-driven
scent"). "DG/TTS TTS 2.0" strings = that product, never the website.
Established 2026-10-30 (dataset + parfumo). [catalog]
