**B&M abbreviation cluster (maker/community-canonical — resolve per
abbreviation, never by edit distance)** [catalog]:
- **SoA** = **S**oapmakers **o**f **A**wesometown — the April 1, 2017
BETA release of the Barrister's Reserve base (Daily Lather B&M
history; maker's ingredient sheet: "Barrister's Reserve (Beta -
SoA)"). Notes: passion fruit, lavender, sandalwood, citrus, ylang
ylang. Established 2026-11-02.
- **LPC** = **L**e **P**etit **C**hypré — the MAKER'S OWN abbreviation
(Daily Lather Latha table: "LPC will make you feel ready for
anything!"). Latha base (discontinued Feb 2018; Soft Heart return
Dec 2019). Established 2026-11-02. **Never expand to Le Grand
Chypre** — that is LGC.
- **LGC** = **L**e **G**rand **C**hypre. Established (community).
- **LLC** = **L**ime, **L**avender, **C**edarwood — the early B&M scent
(B&B 2014 sampler; dataset 2017 "B&M LLC" ×6 authors). Established
2026-11-02. Never the 2024 "Lime" seasonal (a different product).
"LLCW" = "LLC with X" combo pattern (W = with), never a product.
- **C2** = **C**itricuyá second run (June 2018; Daily Lather: "A second
and final run named 'C2' appeared June 2018"). Posters use C2 for the
scent generally ("Citricuyá (C2)", "C2 AS", "C2 edp", "Omnibus
Tester C2"). Established 2026-11-02. Never B&M 42 (distinct product).
