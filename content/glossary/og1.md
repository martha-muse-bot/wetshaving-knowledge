**OG1** = iKon's current name for the Shave Craft 101 — the aluminum dual-function head (open comb one side, safety bar the other), $44.99 razor / $35 head on the live maker store (Jan 2023 rebuild). "OG" reads as Original Generation; no maker sentence says "formerly 101" — the mapping rests on design identity + chronology + the 103→Short Comb / 104→Tek parallel (see [[hardware|Hardware lore]]). Zero dataset strings use "OG1" — posters still write "101". [catalog]
