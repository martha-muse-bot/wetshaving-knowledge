*Confidence: established · Learned: 2026-10-31 · Source: [[Glossary]]*

**XSE** = Zenith's **unbleached-boar variant suffix** — a factory code,
NOT an acronym (no source spells out the letters; never expand them).
Established by correlation 2026-10-31: every XSE-coded model is an
unbleached/natural-knot boar — 80B XSE (Sharpologist boar-brush-bounty:
"natural (light brown) boar," bought to compare against the bleached
B08-A26 counterpart), 506U XSE (B&B 615177: "olive wood-handled
unbleached"), 507U XSE (B&B 615177 + YourShaving 2021 "new Zenith
Unbleached boars," 27×56 black-resin short/tall — the XSE line).
Dataset self-corroboration: posters write "XSE" and "unbleached" in
the SAME string ("Zenith 507N XSE 27.5mm x 57mm Unbleached Boar
Bristle" ×94, "Zenith 80N XSE - Unbleached Boar" ×27, "ZENITH-
A28 XSE 28mm boar unbleached." ×19 — sotd_2016–2026 full scan). The
rest of the code decodes via The Gentle Shave's Zenith cross-reference:
**U = olive-wood handle** (M5 "506U Manchurian" = olive wood; M11
"507/U/Manchu" = olive; dataset "506U XSE - Olive Wood Handle" ×34),
**ALL = aluminum handle** — and the bleached contrast model is the
**506ALL SE** ("aluminum handled bleached," B&B 615177), so **SE
marks the bleached variant, XSE the unbleached one**.
Do NOT read XSE as "eXtra Soft": unbleached Zenith boars are "the
stiffest scrubbiest boars around" (B&B 577997), and the "XS"/"E.S." =
extra-soft code lives in the HORSE line (B&B 569441's "507U XS 27mm
extra soft horse brush"; E1–E3 "506U/L Horse E.S." in the cross-ref).
Established 2026-10-31 (Sharpologist + B&B + YourShaving relay).

below as the correction trail).
**ADDENDUM 2026-10-31 ~12:10 CDT — full code anatomy RESOLVED
(established by correlation):** the code is two orthogonal axes —
HANDLE letter(s) + KNOT suffix (SE/XSE/absent):
- **B = bianco (white/cream plastic handle).** salononline.com.au
"Zenith 80b Cream Handle Shaving Brush"; B&B 615177: "Zenith white
plastic handled unbleached, 80B XSE"; Sharpologist 80B XSE: solid
(not hollow) white plastic handle.
- **N = nero (black resin handle).** B&B 621043: YourShaving's 2021
"new Zenith Unbleached boars" (27×56) in black resin short/tall =
the 507N XSE line (dataset "Zenith 507N XSE 27.5mm x 57mm
Unbleached Boar Bristle" ×94); the 507U XSE olive-wood twin proves
the handle-letter axis independent of the XSE knot axis.
- **U = ulivo (olive wood)** (already established), **ALL =
aluminum** (already established).
- **80B vs 80N = HANDLE split, not knot split:** the 80-series is the
big Zenith boar (~27mm × 64mm); 80B = cream/white handle, 80N =
black handle. Both take the XSE (unbleached) suffix — Sharpologist
"80B XSE natural (light brown) boar"; dataset "Zenith 80N XSE -
Unbleached Boar" ×27 (2025–2026). RazoRock Blondie = rebranded
Zenith 80N (B&B 648179, 649150 — see [[Product aliases]]).
- **SE scope WIDENED (established):** SE is the line-wide bleached-knot
suffix, NOT aluminum-only. Full-corpus dataset scan: 625 SE strings
across 20+ models — 506B SE ×102, 505CB SE ×43, 505BC SE ×39+32+8+2,
2004/B SE ×32, 508A SE ×31, 507U-SE ×30, 510 SE ×28+23, 502NK SE
×20+8 ("Black Resin Boar"), 205WEN SE, 506C SE ("506C - 27mn SE
(Bleached Boar)" — poster-explicit), 506ALL SE ("Aluminum Handle"),
Murano SE, Kintsugi 505CB SE, Cobalt Blue 505BC SE, A26 SE.
Poster-explicit twice: "Zenith 505BC SE 28mm Bleached Boar" ×32
and "Zenith - 506C - 27mn SE (Bleached Boar)" ×2 — so SE is
established as the bleached variant across handle letters (olivewood,
cobalt blue, kintsugi, black resin, aluminum, cream). **Catalog:**
bare "Zenith 80B" (dataset 2021–2023, ~83 uses) carries the handle
letter (B = cream handle, certain) but NO knot suffix — do NOT read
bleached or unbleached from the bare code. P-17: one 80-series model
entry; B/N handle and SE/XSE knot are attributes, not entries.

**ADDENDUM 2026-11-01 — four XSE-adjacent leads RESOLVED + one
correction (see [[Hardware lore]] for the full factory-code anatomy
from The Gentle Shave's cross-reference):**
- **(a4) Bleached 80B SKU — NEGATIVE, RESOLVED:** no "80B SE" exists
anywhere. Corpus: zero "80B SE" strings 2016–2026; the decoder has
no 80B SE row; Sharpologist's bleached counterpart to the 80B XSE
is the **B08-A26** (aluminum handle) — the bleached 80-style brush
lives in the B-series. The 80-series is unbleached-only at retail;
bare "80B" reads as the unbleached (XSE-era) product. [catalog]
- **(a5) 505CB vs 505BC — RESOLVED as DISTINCT:** 505CB ↔ Kintsugi
(poster-attested, always SE; 49 hits 2021–2022 + 2 in 2025);
505BC ↔ Cobalt Blue (poster-explicit "28mm Bleached Boar"; 261
hits 2021–2026, some sold as loose knots for re-knotting). Do NOT
expand the CB letters — no source decodes them. [catalog]
- **(a6) Horse-line codes — RESOLVED:** XS = "Extra Soft" horse
(poster-explicit "506 N XS (extra soft horse)" ×36; decoder E1–E3
"Horse E.S." rows). **WARNING: XS (horse) ≠ XSE (boar) — one
letter apart, opposite axes; never conflate.**
- **205WEN DECODED (established):** NOT a horse code — the backlog
misfiled it. Decoder: NEW-205 = wenge-wood-handle boar, 24×47;
WEN = wenge; SE = bleached (Gerry7070 poster-explicit "bleached
205WEN" ×9, 2026). All 35 corpus hits are Gerry7070's brush.
[catalog]
- **(a3) handle-color letters — REFINED, "bianco" hypothesis
corrected:** decoder pins N = nero (black: "barber black" 506N),
A = white ("barber white" 506A); B is the 80-series' cream/white
PLASTIC handle letter, NOT an Italian word — drop "bianco" until a
maker source says it. U = olive wood, ALL = aluminum (stand).
Master decoder = The Gentle Shave's Zenith code cross-reference
(thegentleshave.com, read 2026-11-01): model numbers are size
families (205=24mm, 502=24.5mm, 506/507=27–27.5mm, 505=28mm,
508=31mm), fiber letters B/E/H/M/N/P/S/T (boar, extra-soft horse,
standard horse, Manchurian, synthetic, silvertip, TS synth, best
badger). [[Method note]]: retailer code-cross-reference pages are a
first-class hardware-lore source.
