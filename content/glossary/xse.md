**XSE** = Zenith factory/retailer knot code seen ONLY on unbleached-boar
models ("Zenith 506U XSE", "80B XSE", "502B XSE" — B&B + yourshaving
copy). **LEAD — no verified expansion; never expand it.** Do NOT
conflate with the E-series "E.S." = Extra Soft HORSE line (The Gentle
Shave cross-reference E1–E3). Learned 2026-10-30.
