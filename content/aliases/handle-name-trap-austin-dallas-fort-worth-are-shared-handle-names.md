[catalog] **Handle-name trap — Austin / Dallas / Fort Worth are shared handle names:** the same three Texas-city names were DE3P handles in 2017 (JohnB413: "RR Baby Smooth on Stirling Dallas Handle", "Maggard Slant on Stirling Fort Worth Handle") AND SSS handles in 2021. A bare handle name never decides which razor; the plate (ST/HA) or the "Stainless DE"/"SSS" marker does.
