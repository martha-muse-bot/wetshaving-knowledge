[catalog] **Fanchurian version ≠ brush identity.** The loose-knot channel (v25–v32 sold as knots, $65–67) means a version string can be a re-knot in ANY handle — e.g. the v32 debut is a Grizzly Bay Ghost re-knot, six days after the knot listing went live. Never identify a brush from its knot version alone; handle maker + coin/scent decide. v25 = first spec change since v5 (maker copy); v19 = "the immortal" benchmark; v30 = the scrubbier anomaly.
