**[[lineages/method-note|Method note]]:** a dupe target can be pinned from the dataset notes alone when the note quotes the original's note pyramid — NoBudsChill's pyramid matched the canonical Pour Homme listing note-for-note, which is stronger than a bare "it's a Paco dupe" claim. When a first-use note pairs the product with the original in the FRAGRANCE field (hawns), that pairing is itself evidence of the intended original.
