**[[lineages/method-note|Method note]]:** a collapsed CDX query returns the FIRST capture per URL key — the 2019-07-21 SS-component dates and 2019-09-19 SB-aluminum date are first-capture dates, i.e. listing-existed-by dates, not launch days; the B&B Apr 27, 2019 "not yet released" post supplies the lower bound. A first CDX `[]` paired with the "Temporarily Offline" page is invalidated, not a negative — this run's first products/* query flapped exactly that way and the retry returned 331 rows. And a Shopify `products.json` `created_at` is a listing-creation date, not a launch date — the Bison aluminum listing (created 2023-11-22) predates first SOTD use (Dec 28, 2023) by five weeks.
