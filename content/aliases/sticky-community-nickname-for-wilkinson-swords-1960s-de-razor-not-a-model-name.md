**[catalog] "Sticky" = community nickname for Wilkinson Sword's
1960s DE razor (not a model name, not the modern Classic).**
Dataset strings "Wilkinson Sticky" / "Wilkinson Sword Razor
(aka Sticky)" 2019–2025; posters date it to the 1960s, and
a 2020 note credits the design to Sir Kenneth Grange
(Design Museum's Grange retrospective confirms he designed
Wilkinson Sword razors over decades, but does not name the
Sticky specifically — Grange link is a lead, nickname +
1960s DE identity established). Comb type unpinned — never
cite the Sticky as an open comb. Source: dataset strings +
