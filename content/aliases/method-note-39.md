**[[lineages/method-note|Method note]]:** a fragrance-field row is not proof of an EdT — check whether the same author's row has soap: None and notes describing a shave with the soap. One author's template quirk, cross-validated through the set rule, can verify a phantom product. The guard is the same as the "notes-field co-occurrence" rule from the TSM audit: read the full row before counting a field as a product.
