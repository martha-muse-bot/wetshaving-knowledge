**[[lineages/method-note|Method note]]:** a Shopify `created_at` dates the CURRENT listing, not necessarily the launch — Baklava's Club VIP listing (2023-11-20) postdates its first dataset use (2022-07-14); Novelist's VIP soap listing (2021-06-25) postdates its VIP splash listing (2017-02-14) by 4+ years. Use the earliest listing per scent as a latest-possible launch date and cross-check against first dataset use. And: a curated scent list built from memory will miss scents — the full "[[glossary/the-club|The Club]]" string census found 16 scents the 05:06 list lacked.
