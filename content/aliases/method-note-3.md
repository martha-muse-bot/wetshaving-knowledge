**[[lineages/method-note|Method note]]:** a note's razor FIELD decides what the note describes, not a keyword in the note text — the "roller bar" misfiling happened because the note mentioned magnetic plates while its field named another razor. Always print the razor field alongside any note quote before attributing a feature.
