**Eucris trap — SINGLETON, no second mis-route:** the K1986 2020 row is
the only Trumper cream string in the corpus that routes to the wrong
sibling (GFT -> Eucris by subset-rev). Creating the GFT cream entry
(323) fixes it; no other row needs re-routing and no matcher change is
owed. The mechanism (subset-rev matches brand+format, ignores URLs)
fires only when the scent token is absent from the visible string —
future bare brand+format Trumper cream strings are P-11 ambiguous,
never auto-folded to the first sibling.
