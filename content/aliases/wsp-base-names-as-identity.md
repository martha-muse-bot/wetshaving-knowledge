[catalog] **WSP base names as identity:** Formula T (tallow) vs Rustic (vegan) is a scent+base key across the WSP line — same scent in both bases = two products (maker: "The only difference is in the T"). The cream is a third format, never a base variant of either soap. This is the same scent+base discipline as DG Milksteak/Icarus/Bison and B&M Excelsior/Glissant ([[lines|Product lines]]), applied to a living maker.
