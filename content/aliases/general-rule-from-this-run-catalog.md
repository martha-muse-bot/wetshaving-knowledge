**General rule from this run [catalog]:** for the heritage British
houses (DRH, Trumper, and by extension TOBS/Truefitt & Hill), a
'cream'-worded string on a soap entry is evidence of a PARALLEL FORMAT
first and loose usage only after the maker range is checked — these
houses sell both formats in the same scent as a matter of course. The
Moon Soaps pattern (a cream-only maker whose posters call the cream
"soap") is the exception, not the rule, and its author set does not
overlap the DRH/Trumper authors at all.
