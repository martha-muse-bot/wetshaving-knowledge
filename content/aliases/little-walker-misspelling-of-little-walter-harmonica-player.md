[catalog] **"Little Walker" = misspelling of Little Walter (harmonica player).** The Sessions unboxing video description writes "Little Walker"; maker copy says "Little Walter" (correct — Walter Jacobs). Any dataset "Little Walker" string is the same tribute, never a second musician. Note the same trap as "Mather"/"Mather" class errors: a YouTube description is not the authority over maker copy.
