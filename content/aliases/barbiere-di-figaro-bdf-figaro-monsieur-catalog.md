**Barbiere di Figaro (BdF) ≠ Figaro Monsieur [catalog]:** BdF is a Netherlands RETAILER (barbieredifigaro.nl) whose house scents (Mistero, Classico, Esclusivo, Raffinato, Italian Fern) are TFS-made. Zero dataset rows for Mistero/Esclusivo/Raffinato — never create BdF entries on the Figaro name alone.
- **CORRECTION 2026-11-25 (learner run, (409)) [catalog]:** "Italian Fern" is NOT a BdF scent — it is a TFS scent (dataset's one row, 2019-07-18, attributes it to TFS; no BdF listing ever carried it). BdF scents = five: Classico, Distinto, Esclusivo, Mistero, Raffinato. Distinto is the fifth scent (2016 launch, maker-attested TFS-made). See [[lineages|Lineages]] run section 2026-11-25 ~21:06.
